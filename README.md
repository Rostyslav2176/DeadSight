# DeadSight
## Game Overview:
Deadsight is a top down 3D rougulike. It is set in the noir city where player plays as a detective stuck in the timeloop. In order to break the loop he is forced to kill all the enemies on his way. Every time player dies game starts from the beginning.

Link to project: https://rostyslav2176.itch.io/deadsight

## How to Play:
WASD - move around

Ctrl - crouch

Shift - dash

Left mouse button - shoot

## How to run the application:
### Github Installation
  1. Make sure you have Unity 2022.3.11f installed or are comfortable with version upgrading.
  2. Download Zip.
  3. Extract file to desired location
  4. Open extracted folder in Unity
